# 01 读稿抽资源

目标：写代码前，把稿子转成「结构化的可编码输入」。

## 1. 读图（模型无原生视觉时）

DeepSeek 等无视觉模型，用 `vision.cjs` 调 `qwen-vl-max`（本次验证可用）。如果项目里已有这个脚本就直接复用；没有就用 `scripts/vision.cjs` 骨架补一个，本质是：把图片 base64 交给多模态模型，拿回文字描述。

要点：
- 一次只描述**一个页面**，别让模型一次概括整份稿。
- 提问要具体：结构树、主色、字号、字体、关键切图、固定尺寸。

调用示例：

```bash
node vision.cjs "E:\...\APP高保真\家族树-拆分图层.png"
```

返回的描述不是最终答案，要**复述成"我读到的布局"给用户确认**（元素位置/大小/间距/颜色逐项对）后再编码。

## 2. 必须产出的 4 件事

1. **页面清单**：完整列出所有屏 + 页面间跳转关系。
   例：Splash → Register → Onboarding → Home →（Chat半/全 · Tools · Family · Messages · Profile）。
2. **设计 token**：主色/辅助色、深色主题色、功能色、字号阶梯、圆角。（没给品牌色时用占位，见 00 §6）
3. **字体**：设计用字体（如 Alibaba PuHuiTi），确认有没有 .otf/.ttf 文件。
4. **切图清单**：哪些是图（logo、头像、背景、icon），哪些能代码画。**列清单主动问用户要素材**，逐一导出到 `src/assets/`；用户没给的标「占位」，按苹果 HIG 留空位（见 00 §8）。

## 3. 量基准尺寸

读出稿子的固定宽高（默认 iOS **390×844** / 安卓 **360×800**，量设计稿替换）。**这个数字贯穿后续所有缩放/图标计算**，先确定它再往下走。

读 PNG 宽高（IHDR 头：字节 16–19 是宽，20–23 是高）：

```powershell
$b = [System.IO.File]::ReadAllBytes('xxx.png')
$w = [int]$b[16]*16777216 + [int]$b[17]*65536 + [int]$b[18]*256 + [int]$b[19]
$h = [int]$b[20]*16777216 + [int]$b[21]*65536 + [int]$b[22]*256 + [int]$b[23]
"$w x $h"
```

⚠️ 别用 `-shl` 位移（PowerShell 5.1 有 bug，只返回低字节，如把 1796×3824 读成 4×240）。
